# Bili Lucky

<p align="center">
  <img src="design/icon-512.png" width="160" alt="Bili Lucky 图标">
</p>

一个运行在 B 站动态详情页内的 Chrome 扩展。它会低频分页读取评论、按用户 MID 去重，并在抽奖时只验证被抽中候选人是否关注当前登录账号。

## 功能

- 自动从动态详情解析真实的评论区 `oid` 与 `type`
- 使用当前 WBI 签名接口按时间游标读取全部主评论
- 在“评论”或“转发”中选择一种参与方式；评论模式可选择继续读取楼中楼回复
- 始终按 MID 去重，并自动排除当前登录账号
- 可选择是否仅从关注当前账号的用户中抽取
- 1.5–8 秒请求间隔，每次自动加入 ±20% 随机停顿
- 按用户 MID 去重，同一用户的不同评论会合并保存
- 使用 `crypto.getRandomValues` 随机打乱候选池
- 只对抽中的候选人逐个查询“目标用户 → 当前账号”的关注关系
- 未关注者自动淘汰并继续抽取，直到达到设定人数或候选池耗尽
- 页内弹窗展示中奖者头像、昵称、评论和关注验证结果
- 收集与抽奖过程均可停止

## 安装

1. 执行 `npm install` 和 `npm run build`。
2. 打开 Chrome 的 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `dist/chrome-mv3`。
5. 登录 B 站后，打开一条动态详情页，例如：
   `https://t.bilibili.com/1236727809932525577`
6. 点击页面右下角“评论抽奖”，或点击扩展图标打开面板。

也可以直接解压 `dist/bili-lucky-1.0.0-chrome.zip` 后加载其中的扩展目录。

## 使用建议

- 默认 3 秒间隔适合一般评论区；评论量很大时建议调到 4–6 秒。
- “包含楼中楼”会为回复较多的主评论增加分页请求，完整收集可能需要较长时间。
- 抽奖期间不要切换登录账号。关注验证以当前浏览器中的 B 站登录账号为准。
- 扩展不会绕过验证码、登录限制或平台风控。若 B 站返回访问限制，请停止任务并稍后再试。
