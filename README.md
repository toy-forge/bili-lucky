# Bili Lucky

<p align="center">
  <img src="design/icon-512.png" width="160" alt="Bili Lucky 图标">
</p>

一个运行在 B 站动态详情页内的 Chrome 扩展。通过「设置规则 → 候选人照片墙 → 抽奖动画 → 中奖结果」完成抽奖，低频收集互动、按 MID 去重，只对随机抽中的候选人校验中奖资格。

## 功能

- 三种参与方式：评论、转发、同时评论和转发（取用户交集）
- 评论模式和交集模式可选择是否包含楼中楼；关闭后不计入接口内嵌回复
- 转发模式只读取转发，不请求评论区
- 始终按 MID 去重，合并同一用户的互动，并排除当前登录账号
- 可选中奖资格：关注当前登录账号、关注数量范围、粉丝数量范围、动态数量范围
- 数量上下限均包含边界；留空表示该方向不限，启用范围后至少填写一端
- 收集完成后展示头像照片墙，支持昵称 / UID 搜索和批量加载
- 悬浮、键盘聚焦或点击头像，可查看评论与转发内容
- 使用 `crypto.getRandomValues` 随机打乱候选池，展示头像滚动动画，并适配减少动态效果偏好
- 抽中后逐位校验，不合格者继续抽取；校验接口失败会暂停，不把未知数据当作不合格
- 结果展示头像、昵称、UID、关注数、粉丝数、动态数及评论 / 转发内容
- 展示本轮规则、中奖人数与资格校验记录；停止或候选池耗尽时保留已确认的中奖者
- 1.5–8 秒请求间隔，每次自动加入 ±20% 随机停顿
- 修改参与方式或楼中楼设置后需要重新收集；中奖资格可在抽奖前调整

## 安装

1. 执行 `npm install` 和 `npm run build`。
2. 打开 Chrome 的 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `dist/chrome-mv3`。
5. 登录 B 站后，打开一条动态详情页，例如：
   `https://t.bilibili.com/1236727809932525577`
6. 点击页面右下角“动态抽奖”，或点击扩展图标打开面板。

也可以执行 `npm run zip`，解压生成的安装包后加载其中的扩展目录。

## 使用建议

- 默认 3 秒间隔适合一般评论区；评论量很大时建议调到 4–6 秒。
- “包含楼中楼”会为回复较多的主评论增加分页请求，完整收集可能需要较长时间。
- 关注验证以当前浏览器中的 B 站登录账号为准，不一定是动态作者。抽奖前会确认账号未变，抽奖期间不要切换账号。
- 数量筛选只在抽中后查询。未启用数量筛选时，资料接口失败不影响中奖，结果会标明数据暂不可用。
- 停止收集需要重新收集；停止抽奖会保留当前结果。「重新抽奖」发起独立新一轮，之前的中奖者仍可参与。
- 扩展不会绕过验证码、登录限制或平台风控。若 B 站返回访问限制，请停止任务并稍后再试。
